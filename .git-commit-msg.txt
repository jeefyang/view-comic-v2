feat(history): 新增历史与书签页，云端增量同步；统一滚动条外观

历史与书签
- 导航栏新增「历史」页（/history），两个标签页分别列历史与书签，
  历史同时记录打开过的书（含页码/总页数）与打开过的书库。
- 数据存云端 userConfig 的 readHistory / bookmarks，最多 200 / 500 条；
  历史与书签卡片都显示「书库名 / 路径」，可单条删除、可清空。
- 阅读页悬浮菜单与点击区域动作都能加/取消当前页书签，
  书签可直接跳到那本书的那一页。
- 根目录书的名字归一：服务端给根目录的 basePath 与 baseFile.name 都是 "."，
  归一后为空串会让记录直接 return，改用 bookDisplayName() 兜底。

增量写入接口
- 新增 patchHistory / patchBookmarks / patchTapZoneLayout 三个键，
  单条 upsert / remove / clear，服务端做合并、去重与截断。
- 前端 historyData.ts 改为变化队列（pendingHistory / pendingBookmarks），
  逐条推送、成功才出队、失败 8 秒后重试；4 秒防抖，离开阅读页立即 flush。
- 点击区域布局改用 patchLayout(name, zones)，不再整包上传所有布局。
- 整包 setUserConfig 保留给其它配置字段。

滚动条
- 新增 src/assets/scrollbar.css：全局 8px 圆角半透明滑块，轨道透明，
  Firefox 与 WebKit 两套写法；naive-ui 的 --n-scrollbar-* 变量内联在元素上，
  用 !important 覆盖。
- 阅读设置抽屉与书库抽屉改用 naive 滚动条（:native-scrollbar="false"）。
- 书架列表、VirtualList、瀑布流、设置页仍刻意隐藏滚动条，未改动。
